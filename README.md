**Global Sales & Profit Performance Dashboard**

## 📊 Project Overview
An interactive Power BI dashboard designed to analyze global sales and profit performance. The dashboard helps explore sales trends, product performance, category-wise sales, and customer segment contributions through interactive visualizations.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Modeling
- Data Visualization
- Bookmarks, Tooltips & Drillthrough
- Interactive Slicers

## 📌 Key Performance Indicators (KPIs)
- Total Sales
- Total Quantity
- Total Shipping Cost

## 📈 Dashboard Features
- **Sales by Category:** Compare sales across Technology, Furniture, and Office Supplies.
- **Top 5 Products by Sales:** Identify the highest-performing products.
- **Monthly Sales Trend:** Explore changes in sales throughout the year.
- **Sales by Segment:** Analyze sales contributions from Consumer, Corporate, and Home Office segments.
- **Interactive Filters:** Filter dashboard insights by year and region.
- **Bookmarks:** Switch between Sales and Profit views.
- **Report Tooltips:** View additional performance details when hovering over visuals.
- **Drillthrough Pages:** Explore detailed Sales and Profit analysis.

## 🗂️ Data Model
The project uses a fact table and dimension tables:
- Fact_Orders
- Dim_Product
- Dim_Customer
- Dim_People
- Dim_Returns

## 🎯 Project Objective
To transform sales data into meaningful visual insights and make it easier to explore business performance through an interactive dashboard.
